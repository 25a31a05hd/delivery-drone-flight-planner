Algorithm Engine

  • BFS (Breadth-First Search): Evaluates grid terrain to create a distance matrix avoiding all no-fly zone obstacles.
  • Held-Karp Dynamic Programming: Finds the mathematically guaranteed shortest TSP tour using bitmask DP in $O(N^2 2^N)$ time.
  • Greedy Nearest-Neighbor: Ultra-fast $O(N^2)$ heuristic fallback for large point sets.
